# Data notice

- This repository publishes aggregate results (accuracy, calibration, cut-offs and similar numbers) computed from
  answers returned by TypeSafe AI's Jev API for public datasets. It does not publish dataset records, model
  answers per item, API keys or request logs.
- Each dataset keeps its own licence and terms; the Method page of the site lists the licence recorded for each
  (some are marked "unverified": we did not confirm them). Cite the datasets, not this repository, when you use them.
- The questions shown on dataset pages are our own wording; dataset text is not reproduced.
- Jev is a product of TypeSafe AI. This project is independent and unofficial.
